
# Student Assignment Tracker

## Project Description
Student Assignment Tracker is a console-based Python application that uses MySQL to manage student assignments.

## Features
- Add assignments
- View assignments
- Update assignment details
- Change assignment status to Pending or Completed
- Delete assignments

## Technologies Used
- Python
- MySQL
- XAMPP
- phpMyAdmin

## Database
Database name: student_assignment_db

Table name: assignments

## How to Run
1. Start MySQL in XAMPP.
2. Import schema.sql using phpMyAdmin.
3. Install the MySQL connector using:

   py -m pip install mysql-connector-python

4. Open PowerShell in the project folder.
5. Run the application:

   py main.py
